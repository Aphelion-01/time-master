# Time Master 原生原型

macOS 26+，Apple Silicon；使用系统 SwiftUI Liquid Glass。没有主窗口，常驻菜单栏。

运行 `zsh build.sh`，然后打开 `build/Time Master.app`。需要 Xcode。
首次预览使用：`open 'build/Time Master.app' --args --demo`。仅没有数据文件时创建两个演示事件，普通启动为空状态。

已实现：事件增删改、起算/截止时间、点阵/圆环/刻度、五种强调色、拖动位置记忆、单卡/全局显隐、JSON 原子保存和导入导出。
卡片悬停显示更多操作，双击编辑。编辑使用临时原生窗口，尚未做菜单栏内原位切换。
数据：`~/Library/Application Support/TimeMaster/events.json`。

当前是本机原型：尚无通知、开机启动、归档、撤销删除、iCloud、Intel 构建、旧系统材质回退。点阵超过84天显示明确标注的全周期比例，不再声称一格一天。以日历日显示主数字，圆环/刻度按精确时长显示剩余比例。
本地 ad-hoc 签名，不是公证发布版。未接入网络服务。

## 0.1.1 卡片与吸附修正

- 保留深色透明材质，固定深色卡片外观；参考样例统一为 430×334 pt，标准 SF 数字、固定留白与图形位置。
- 刻度改为分段时间轴和“今天”标记；圆环显示一位小数百分比；点阵单元固定排列。
- 卡片主体可直接拖动，双击编辑，右键操作；右上角菜单继续可用。
- 松手后在 16 pt 范围内吸附，屏幕边距和相邻卡片间距为 12 pt；Shift 松手跳过吸附。位置持久化。
- 支持 macOS 暴露了独立窗口边界的系统小组件；系统合并容器或不可读取的组件不能可靠吸附，不申请录屏权限。
- `zsh test.sh` 检查日期、JSON 与吸附几何；运行二进制 `--verify-ui` 检查原生卡片尺寸、外观、拖动命中路径。

## 0.2.0 弹性、自适应布局与新设置

- 拖动有速度相关的轻微倾斜、拉伸和滞后，松手弹簧回正；可中断，跟随系统“减少动态效果”。不连续改变模糊值。
- 拖动卡片右下角缩放，尺寸范围 280×140–760×540 pt，自动切换紧凑、标准、宽幅、展开四档排版；位置与尺寸在松手后保存。
- 全新设置：菜单栏更多菜单或 `⌘,` 打开，左侧搜索与分组，右侧实时预览。外观按事件调整；交互偏好全局即时保存。事件编辑的取消不会修改原数据。
- 可设置弹性开关、吸附开关、系统小组件吸附、吸附范围、卡片间距和背景深度。保留深色透明材质。
- `--settings` 启动时直接打开设置；`--verify-ui --snapshot-dir <目录>` 渲染原生视图并检查窗口排版。
- 旧版 JSON 不需要手动迁移。新增尺寸字段缺省时使用原来的 430×334。
- 参考 Raycast Settings、Linear Preferences 和 Apple HIG，详见本次设计说明。界面渲染检查不是 GPU 帧率基准；手势的弹性感受仍需实际使用反馈。

## 0.3.0 桌面图层与 DMG

设置 → 卡片外观 → 桌面图层：
- 始终置顶：普通窗口上方，切换应用时仍可见；保留全屏辅助窗口的系统行为。
- 普通窗口：与普通应用窗口一起前后切换，跟随所在桌面空间。
- 固定桌面：桌面图标层之上、普通应用窗口之下，在各桌面空间显示；仍支持拖动与缩放。

图层选项作用于所有卡片，即时应用并保存。菜单栏更多菜单也可快速切换。

`zsh build.sh` 编译，`zsh package.sh <输出目录>` 生成包含应用、Applications 入口与安装说明的 DMG，并写出 SHA-256。
当前安装包目标为 Apple Silicon、macOS 26+，使用本地 ad-hoc 签名，未进行 Apple 公证。安装包不包含个人事件数据。
验证覆盖：三种原生层级与空间行为、当前偏好与几何保留、DMG 校验与挂载、安装包复制后的签名、架构、版本及原生窗口运行。

## 0.4.0 组合记录

菜单栏“组合窗口 → 新建组合”，或设置“组合记录”中创建。选择至少两个事件，提供余量对照、共同时间轴、并列卡片三种图形；支持按截止日期或自定顺序排列。

组合使用一张深色透明玻璃面板，拖动标题移动，右下角缩放，内部滚动与点按成员编辑；继承吸附、弹性和桌面图层。成员引用原事件，不复制、不改动原日期。可主动隐藏独立卡片，解散组合不删除原事件。

组合保存在同目录 groups.json，旧事件文件保持不变。新版导出包含事件与组合，仍接受旧版数组备份。位置/尺寸仅松手保存；排序与共同时间轴在一次视图求值中计算一次，共用刷新时钟，不为每个成员叠加玻璃层。

新增验证：成员去重、源事件实时引用、排序、共同时间尺度、组合几何、旧/新备份与无效引用校验；隔离存储持久化、解散时事件保留、损坏文件不覆盖；原生组合窗口、图层、标题拖动命中与三种图形渲染。图形手感与完整点击流程还需实机体验；此轮 UI 自动化连接超时。
